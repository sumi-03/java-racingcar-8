# 📌 자동차 경주

---
## 🧾 기능 요구 사항
### *"초간단 자동차 경주 게임을 구현한다."*

> **주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.** <br>

> **각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.** <br>

> **자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.** <br>

> **사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.** <br>

> **전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.** <br>

> **자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.** <br>

> **우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.** <br>

> **사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.**


___
## 🖥️ 입출력 요구 사항

> ### 📥 입력
> - 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
> ```text
> pobi,woni,jun
> ```
> 
> - 시도할 횟수
> ```text
> 5
> ```

> ### 📤 출력
> - 차수별 실행 결과
> ```text
> pobi : --
> woni : ----
> jun : ---
> ```
>
> - 단독 우승자 안내 문구
> ```text
> 최종 우승자 : pobi
> ```
>
> - 공동 우승자 안내 문구
> ```text
> 최종 우승자 : pobi, jun
> ```

> ### 💡 실행 결과 예시
> ```text
> 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
> pobi,woni,jun
> 시도할 횟수는 몇 회인가요?
> 5
>
> 실행 결과
> pobi : -
> woni :
> jun : -
>
> pobi : --
> woni : -
> jun : --
>
> pobi : ---
> woni : --
> jun : ---
>
> pobi : ----
> woni : ---
> jun : ----
>
> pobi : -----

>
> 최종 우승자 : pobi, jun
> ```

## 🧩 구현할 기능 목록

### 🔹 입력 기능
1. **경주할 자동차 이름과 시도 횟수를 입력하라는 안내 문구를 콘솔에 출력한다.**
2. **`camp.nextstep.edu.missionutils.Console.readLine()`을 사용하여 사용자로부터 경주할 자동차 이름과 시도 횟수를 입력받는다.**

### 🔹 입력값 검증 및 값 추출 기능
1. **자동차 이름이 빈칸없이 콤마로 구분된 올바른 형식인지 확인한다.**
   - 형식이 맞지 않으면 `IllegalArgumentException`을 발생시킨다.
2. **시도 횟수가 1 이상의 숫자인지 검증한다.**
   - 잘못된 값이면 `IllegalArgumentException`을 발생시킨다.
3. **검증을 통과한 입력값에서 자동차 이름 목록과 시도 횟수를 추출한다.**

### 🔹 자동차 경주 진행 및 우승자 판별 기능
1. **입력된 이름으로 자동차 객체 목록을 생성한다.**
2. **지정된 시도 횟수만큼 반복하며 각 자동차가 이동할지 여부를 결정한다.**
   - `camp.nextstep.edu.missionutils.Randoms.pickNumberInRange()` 메서드를 사용해 0~9 사이의 난수를 생성한다.
   - 생성된 값이 4 이상이면 자동차를 한 칸 전진시키고 그보다 작으면 정지한다.
3. **매 시도마다 각 자동차의 이동 결과를 기록해 이후 출력 시 사용할 수 있도록 저장한다.**
4. **모든 시도가 끝나면 가장 멀리 이동한 거리를 기준으로 우승자를 판별한다.**
   - 동일한 거리를 이동한 자동차가 여러 대라면 공동 우승으로 처리한다.
5. **최종적으로 각 자동차의 이름과 이동 거리, 우승자 정보를 담은 결과를 반환한다.**

### 🔹 출력 기능
1. **차수별 실행 결과와 최종 우승자 안내 문구를 콘솔에 출력한다.**
   - 각 차수마다 자동차 이름 옆에 이동 거리를 ‘-’로 표시한다.
   - 게임이 종료되면 우승자(복수 가능)를 쉼표(,)로 구분해 출력한다.

## 🚀 개선할 사항 및 주의사항

### 🧠 개선할 사항
1. **1주차 코드 리뷰 피드백 반영**
   - 메서드 이름을 지을 때 더 신중히 고민하고 역할이 명확하게 드러나도록 작성하기
   - Stream API도 적극 활용하기
   - 유틸성 클래스의 경우 @UtilityClass 활용하기
2. **TDD 적용 & 테스트 범위 확대**
   - 입력 검증 뿐 아니라 주요 로직도 테스트 하기

### ⚠️ 주의사항
1. **인덴트(들여쓰기) depth는 최대 2까지만 허용**
2. **3항 연산자 사용 금지**
3. **단일 책임 원칙(SRP) 준수**
   - 하나의 메서드는 한 가지 일만 수행하도록 설계하기
   - 복잡한 로직은 작은 단위로 분리하기
4. **테스트 코드 필수 작성**
   - JUnit5, AssertJ 기반으로 단위 테스트 및 예외 테스트 수행하기
